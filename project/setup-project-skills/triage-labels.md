# Triage States

The skills speak in terms of four neutral workflow states. This file maps those states to the labels, fields, or header strings used in this repo's issue tracker.

| Canonical state | Value in our tracker | Meaning |
| --------------- | -------------------- | ------- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `planned` | `planned` | Accepted and sufficiently understood for scheduling |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a state, use the corresponding tracker value from this table. States describe workflow condition only; they do not assign an implementer.

Edit the right-hand column to match whatever vocabulary you actually use.
